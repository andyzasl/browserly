# Security Policy

## Supported Versions

Only the latest release version of Browserly is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Browserly, please do not report it publicly. Instead, please report it directly by opening a private security advisory on GitHub or by contacting the maintainer at `andy.evil@gmail.com`.

We will review the vulnerability and aim to address it as soon as possible.
